# 보안 콘텐츠 배너 이미지 생성 프롬프트
> v1.2 | 720×405px 앱 웹뷰용 가로형 배너 | v3.7_final 5단계에서 분리

---

## 개요

보안 콘텐츠 생성 프롬프트(v3.7_final) 실행 후 산출된 콘텐츠를 바탕으로 배너 이미지를 생성한다.

**입력값 (콘텐츠 생성 프롬프트 실행 결과에서 가져옴)**
- 카테고리
- 제목
- 행동 가이드 핵심어 (본문 마지막 단락의 4개 항목에서 추출)

---

## 이미지 규격

- **720 × 405 px** (앱 웹뷰용 가로형 배너)

---

## 디자인 스타일

- 플랫 벡터 스타일
- 단순하고 직관적인 구성
- 복잡한 배경, 과도한 그림자, 작은 장식 요소 최소화
- PNG 기준 300KB 이하로 압축하기 쉬운 구조

- 보안 주제를 직관적으로 표현한다.
- 과도한 공포 연출 금지
- 자물쇠, 방패, 스마트폰, 보안 알림 등 일반적인 보안 아이콘 활용 가능

## PNG 추출 규칙 (투명 영역 완전 제거)

### 파일명 규칙

```
휴대폰안심_매거진_배너_YYYYMMDD.png
예) 휴대폰안심_매거진_배너_20260616.png
```

날짜는 **실행 당일의 실제 날짜를 먼저 확인한 뒤** 적용한다. 시스템 시계(`date`)·파일 mtime을 그대로 신뢰하지 말고, 불확실하면 사용자에게 오늘 날짜를 확인한다.

### 추출 절차

SVG 작성 후 반드시 아래 절차로 PNG를 추출한다.

```python
import cairosvg
from PIL import Image
import io

W, H = 720, 405
BG = (배경색 RGB 튜플)  # 예: (14, 14, 26)

from datetime import date
TODAY = date.today().strftime("%Y%m%d")
FILENAME = f"휴대폰안심_매거진_배너_{TODAY}.png"

# 1) SVG → PNG 변환 (정확히 720×405)
png_bytes = cairosvg.svg2png(url="banner.svg", output_width=W, output_height=H)

# 2) RGBA로 열기
img = Image.open(io.BytesIO(png_bytes)).convert("RGBA")

# 3) 불투명 배경 위에 합성 (투명 픽셀 제거)
bg = Image.new("RGB", img.size, BG)
bg.paste(img, mask=img.getchannel("A"))

# 4) 정확히 720×405로 크롭 (캔버스 밖 요소 물리적 제거)
final = bg.crop((0, 0, W, H)).convert("RGB")

# 5) PNG 저장 — 파일명 규칙 적용
final.save(FILENAME, "PNG")
```

> **결과 보장:** 투명·반투명 픽셀 0개, 모드 RGB, 크기 720×405, 캔버스 밖 영역 완전 제거
