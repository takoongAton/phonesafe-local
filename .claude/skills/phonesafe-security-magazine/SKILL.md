# PhoneSafe 보안 매거진 콘텐츠 생성

## 개요

일반 고객의 보안 인식 향상과 피해 예방을 위한 안내형 보안 매거진을 생성한다. 국내 보안뉴스 수집 → 중복 확인 → 이슈 선정 → 900~1,000자 콘텐츠 작성 → docx/pdf 생성 → CSV 이력 업데이트의 6단계로 진행한다. macOS 로컬 환경에서 실제 실행 가능하도록 구성되어 있다.

배너 이미지가 필요하면 콘텐츠 생성 후 [[phonesafe-magazine-banner]] 스킬로 이어간다.

## 작업 폴더 규칙

- 프로젝트 매거진 폴더: `매거진 프롬프트/`
- 이력 CSV: `매거진 프롬프트/magazine_list.csv` (또는 최신 산출 폴더의 CSV)
- 산출물 저장: **실행할 때마다 새 폴더 생성** — `매거진 프롬프트/매거진 컨텐츠/YYMMDD/`. 같은 날 여러 번 실행하면 `YYMMDD_2`, `YYMMDD_3` … 로 겹치지 않게 자동 증가한다(스크립트가 처리). 한 실행의 docx·pdf·(배너 png)는 모두 같은 폴더에 들어간다.
- 이력 CSV(`magazine_list.csv`)는 프로젝트 루트의 마스터 파일 하나만 계속 업데이트한다(폴더별로 나누지 않음).

## 전제 조건 (반드시 준수)

- 국내 보안뉴스 또는 국내 공공기관 공식 권고만 참조한다.
- 뉴스 원문을 복사하지 않고 핵심 사실을 재구성한다.
- 이전 콘텐츠와 동일·유사 주제는 피한다.
- 특정 기업·기관·서비스 책임을 단정하지 않고, 공포심 유발 표현을 쓰지 않는다.
- 본문 마지막에 AI 생성 고지 문구를 반드시 포함한다(관리자 검수 후 게시 전제).
- **날짜는 실행 당일의 실제 날짜를 먼저 확인한 뒤 적용한다.** 시스템 시계(`date`)·파일 mtime이 실제와 다를 수 있으므로 그대로 믿지 말고, 오늘 날짜가 불확실하면 진행 전에 사용자에게 확인한다. 확정한 날짜를 폴더명(`YYMMDD`)·파일명(`YYYYMMDD`)·docx 부제·CSV 발행일에 일관되게 쓴다.

## 워크플로우

### 0단계: 최초 1회 환경 준비

```bash
bash scripts/setup.sh
```

`python-docx`, `reportlab`, `cairosvg`, `pillow` 를 설치한다(이미 있으면 건너뜀).

### 1단계: 기존 콘텐츠 조회 및 중복 확인

`magazine_list.csv` 를 읽어 기존 카테고리·제목 목록을 파악한다. 중복 판단 기준:
- **주제 중복**: 동일 사건이거나 핵심 메시지 80% 이상 유사
- **카테고리 편중**: 동일 카테고리 최근 3회 이상 연속 → 다른 카테고리 우선

CSV가 없으면 기존 콘텐츠 없음으로 간주하고 6단계에서 새로 생성한다.

### 2단계: 실행 요일별 검색 범위 결정 후 뉴스 수집

| 실행 요일 | 검색 대상 기간 |
|-----------|--------------|
| 화요일 | 직전 주 금요일 ~ 당일 직전 월요일 |
| 금요일 | 당일 주 화요일 ~ 목요일 |
| 그 외 | 사용자에게 "화/금 중 어느 기준?" 확인 후 진행 |

`web_search` 로 아래 방식을 모두 실행해 최소 5건 수집(동일 사건은 1건으로 병합). 검색 쿼리·출처·신뢰기준은 `references/news-collection.md` 참조. 검증 가능한 출처가 부족하면 `검증 가능한 출처 부족` 만 출력하고 중단한다.

### 3단계: 카테고리 분류 및 이슈 1건 선정

5개 카테고리(①스미싱/피싱 ②해킹/침해사고 ③개인정보 유출 ④악성코드/앱 ⑤제도/정책) 중 분류. 선정 우선순위: 비중복성 → 파급력 → 최신성 → 사회적 관심도 → 독자 실용성. 5개에 명확히 해당하지 않으면 생성하지 않는다.

**0~3단계 완료 후 아래 형식으로 출력한다:**

```
[기존 콘텐츠 목록]
· (카테고리) 제목 ...
[중복 제외 이슈]
· 제외 이슈 및 사유 (없으면 '해당 없음')
[선정 이슈]
· 최종 선정 이슈 한 줄 요약
```

### 4단계: 콘텐츠 작성 (900~1,000자)

`references/content-guidelines.md` 의 분량·스타일·금지사항을 **반드시** 지켜 작성한다. 구조 요약:

- **카테고리**: `번호) 카테고리명` (예: `3) 개인정보 유출`)
- **제목**: 안내형 문구
- **서론** 50~150자 — 주의 필요성만 간략히
- **본문** 700~800자 — 소제목 없는 2~4개 단락, 첫 단락(상황 묘사) + 마지막 단락(번호형 행동 가이드 4개) 필수
- **결론** 50~100자 — 습관 강조로 마무리
- **AI 고지 문구** (고정, 수정 금지)

작성한 콘텐츠를 `references/content-schema.json` 형식의 JSON 파일로 저장한다(예: 산출 폴더에 `content.json`). 이 파일이 5·6단계 입력이 된다.

### 5·6단계: docx·pdf 생성 및 CSV 업데이트

```bash
python3 scripts/generate.py content.json \
  --base "매거진 프롬프트/매거진 컨텐츠" \
  --csv "매거진 프롬프트/magazine_list.csv" \
  --tags "핵심 키워드, 쉼표 구분" \
  --link "참조 뉴스 URL(선택)" \
  --snapshot
```

`--snapshot` 을 주면 루트 마스터 CSV를 업데이트한 뒤, 그 사본을 실행 폴더 안에 `magazine_list_YYYYMMDD.csv` 로도 남긴다(기존 저장소 폴더 관행과 동일). 필요 없으면 생략한다.

`--base` 를 주면 실행일 기준 `YYMMDD` 폴더를 새로 만들고(겹치면 `_2`, `_3` …) 그 안에 산출물을 넣는다. 한 번에 처리하는 작업:
1. `보안콘텐츠_YYYYMMDD.docx` — 서론/본문/결론 라벨 유지
2. `보안콘텐츠_YYYYMMDD.pdf` — 서론+본문+결론을 라벨 없이 통합
3. `magazine_list.csv` 에 새 행 추가(NO 자동 증가, 상태 "작성 완료")
4. (`--snapshot` 시) 실행 폴더에 `magazine_list_YYYYMMDD.csv` 사본 저장

실행이 끝나면 스크립트가 `📁 폴더: ...` 로 **실제 생성된 폴더 경로**를 출력한다. 이어서 배너를 만들 때 [[phonesafe-magazine-banner]] 스킬에 **이 폴더 경로를 그대로 전달**한다(배너가 별도 폴더를 만들지 않고 같은 폴더에 저장되도록).

폰트는 스크립트가 자동 탐색한다(나눔 → 없으면 macOS AppleGothic). `--csv` 를 빼면 산출물만 만든다.

## 최종 출력 체크리스트

- [ ] CSV 읽기 및 중복 확인 완료
- [ ] 카테고리 번호·명칭 표기, 제목 안내형
- [ ] 서론 50~150자 / 본문 700~800자 / 결론 50~100자
- [ ] 본문 소제목 미사용, 단락 2~4개, 첫 단락 + 마지막(행동 가이드 4개) 구성
- [ ] AI 생성 고지 문구 포함, 금지 사항 미포함
- [ ] 전체 900~1,000자
- [ ] docx·pdf 생성, magazine_list.csv 업데이트 완료
- [ ] (필요 시) phonesafe-magazine-banner 로 배너 생성

## 예외 처리

| 상황 | 대응 |
|------|------|
| CSV 미존재 | 기존 콘텐츠 없음으로 진행, 6단계에서 신규 생성 |
| 검색 기간 내 뉴스 없음 | 검색 범위 1주일 확장 재검색 |
| 모든 이슈가 기존과 중복 | 검색 기간 1주일 확장하여 새 이슈 탐색 |
| 검증 가능한 출처 부족 | `검증 가능한 출처 부족` 만 출력 |
| docx/pdf 생성 실패 | setup.sh 재실행 안내, 콘텐츠 텍스트만 우선 제공 |
| 폰트 미탐색 | NanumGothic.ttf 를 ~/Library/Fonts 에 설치 안내 |
