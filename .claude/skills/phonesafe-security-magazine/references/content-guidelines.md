# 콘텐츠 작성 상세 가이드 (v4.01 기반)

## 목적과 원칙

고객의 보안 인식 향상과 피해 예방이 목적이다. 아래를 반드시 준수한다.

- 특정 기업·기관·서비스의 책임을 단정하지 않는다.
- 확인되지 않은 피해 사실이나 추정을 사실처럼 쓰지 않는다.
- 공포심을 유발하는 표현을 쓰지 않는다.
- 이해하기 쉬운 안내형으로 쓰고, 실제 실천 가능한 보안 수칙을 반드시 포함한다.

## 작성 스타일

- 존댓말 사용, 반말 금지
- 딱딱한 공지문 지양, 친근하고 자연스러운 정보성 콘텐츠
- 모바일 화면에 맞춘 짧은 문단
- 전문 용어 최소화 — 필요 시 괄호로 쉬운 설명 병기
  - 예: `랜섬웨어(파일을 인질로 삼아 돈을 요구하는 악성 프로그램)`

**좋은 예:** "최근에는 공공기관을 사칭한 문자로 가짜 사이트 접속을 유도하는 사례가 꾸준히 발생하고 있습니다."

**나쁜 예:** "공격자는 사회공학 기법을 활용하여 악성 URL 접속을 유도하고 인증정보를 탈취한다."

## 구성별 분량·규칙

### 카테고리
`번호) 카테고리명` 형식. 예: `3) 개인정보 유출`

### 제목
고객이 이해하기 쉬운 안내형 문구.

### 서론 (50~150자)
- 최근 국내 보안 이슈/공식 권고가 있다는 사실만 간략히 전달
- 사건 상세 설명 없이 "왜 주의해야 하는지"만 안내
- 예: "최근 공공기관을 사칭한 문자 사례가 확인되고 있어 각별한 주의가 필요합니다."

### 본문 (700~800자)
2~4개 단락, **소제목 없이**(▶, ##, 굵은 제목 등 모든 형태 금지) 자연스러운 산문.

| 단락 | 역할 | 권장 분량 |
|------|------|-----------|
| 단락 1 | 독자 공감 유도 — 생활 밀착형 상황 묘사 | 150~200자 |
| 단락 2 | 피해 가능성·파급력을 쉽게 설명 | 150~200자 |
| 단락 3 (선택) | 수법을 쉽게 풀어 설명 (기술 용어 최소화) | 100~150자 |
| 마지막 단락 | 번호형 행동 가이드 (필수) | 250~300자 |

단락 2~3은 통합·생략 가능하나, **단락 1(상황)** 과 **마지막(행동 가이드)** 은 항상 포함.

**행동 가이드 규칙**
- 번호형(1~4) 4개 항목
- 각 항목 1~2문장, 60~80자 내외
- 체크리스트처럼 5초 안에 핵심 파악 가능하게
- 불필요한 배경·기술 용어 나열 금지

상황에 맞는 예방 행동을 선택해 구성:
```
링크를 바로 누르지 않기 / 공식 앱·홈페이지에서 직접 확인하기 / 비밀번호 변경하기
2단계 인증 설정하기 / 보안 업데이트 적용하기 / 앱 설치 전 권한 확인하기
의심스러운 요청 한 번 더 확인하기 / 로그인 기록 확인하기 / 사용하지 않는 앱 삭제하기
```

### 결론 (50~100자)
- 행동 가이드를 한 문장으로 정리, 생활 속 습관 강조
- 새 사실·추가 이슈 금지, 1~2문장 마무리

### AI 생성 고지 문구 (고정 — 삭제·수정 금지)
```
※ 본 콘텐츠는 국내 보안뉴스 및 공개된 보안 권고를 참고하여 생성형 AI를 활용해 작성되었으며, 관리자 검수 후 게시되었습니다.
```

## 카테고리별 작성 방향

1. **스미싱/피싱** — 문자·이메일·메신저·QR 사기 수법과 예방. 공식 앱 확인, 링크 클릭 전 멈춤, 개인정보 입력 전 확인.
2. **해킹/침해사고** — 계정 보안 강화, 비밀번호 관리, 2단계 인증.
3. **개인정보 유출** — 동일 비밀번호 위험, 계정 점검, 의심 연락 주의.
4. **악성코드/앱** — 공식 앱마켓 이용, 설치 권한 확인, 불필요 앱 삭제, OS 업데이트.
5. **제도/정책** — 고객이 실천할 보안 설정과 최신 권고를 쉽고 간결하게.

## 금지 사항 (절대 포함 금지)

- **저작권**: 기사 원문/제목 복사, 문장 구조 재현
- **보안 위험**: 실제 악성 URL·피싱 주소, 악성코드 코드, 공격 절차/취약점 악용/우회 방법
- **개인정보**: 전화번호, 이메일, 계좌번호, 인증번호 등
- **사실 왜곡**: 피해 규모 단정, 공격 주체 단정, 특정 기업·기관 책임 단정
- **포맷**: 출처 목록, 작성 기준일, 내부 검수 메모

## 작성 예시 (스미싱/피싱, 3단락)

```
택배 배송 안내, 공공기관 고지문, 지인의 연락처럼 보이는 문자나 메신저 메시지가
늘어나고 있습니다. 링크를 누르면 개인정보를 입력하는 가짜 사이트로 연결되거나,
스마트폰에 악성 앱이 설치될 수 있습니다.

피해를 입더라도 빠르게 알아차리기 어렵습니다. 입력한 개인정보는 다른 사기에
이용되거나 금융 피해로 이어질 수 있어 사전에 확인하는 습관이 가장 중요합니다.

1. 문자나 메신저로 받은 링크는 바로 누르지 마세요. 발신자가 익숙하더라도 공식
   앱이나 홈페이지에서 먼저 확인하세요.
2. 개인정보 입력 전에 주소창의 URL을 꼭 확인하세요. 공식 기관의 주소와 다르면
   즉시 창을 닫으세요.
3. 주요 계정에 2단계 인증을 설정해 보세요. 비밀번호가 유출되어도 계정을 한 번 더
   보호할 수 있습니다.
4. 의심스러운 문자나 링크는 주변에 꼭 알려주세요. 가족·지인과 공유하는 것도 좋은
   보안 습관입니다.
```
