# 배너 디자인 상세 가이드 (하우스 스타일)

> 이 가이드는 `매거진 컨텐츠/*/보안콘텐츠_*.png` 기존 배너들에서 추출한 실제 하우스 스타일이다.
> **새 배너를 만들기 전에 반드시 최근 배너 2~3개를 이미지로 열어(Read) 톤·구도를 눈으로 확인하고 일관되게 제작한다.**

## 이미지 규격

- **1672 × 941 px** (16:9) — 하우스 표준 해상도. `svg_to_png.py` 기본값과 동일.
- 최종 PNG는 RGB, 투명 픽셀 0개.

## 전체 구도 (2단 레이아웃)

```
┌─────────────────────────────────────────────┐
│ [카테고리 칩]                    ╭─────────╮  │  ← 연한 블루 배경
│                                  │ 일러스트 │  │
│  초대형 제목 1줄 (네이비)         │ (스마트폰│  │
│  초대형 제목 2줄 + 강조어(블루)   │ /방패/! )│  │
│                                  ╰─────────╯  │
│  | 보조 문구                                  │
│~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ │  ← 물결 경계
│ ⭘ 캡션 | ⭘ 캡션 | ⭘ 캡션      * AI로 생성… │  ← 하단 네이비 밴드
└─────────────────────────────────────────────┘
```

- 상단 2/3: 연한 블루 배경 + 좌측 텍스트 + 우측 일러스트
- 하단 1/3: 네이비 밴드(물결 상단 경계) 위에 행동 가이드 아이콘 3~4개

## 색상 팔레트

| 용도 | 색상 |
|------|------|
| 배경(연블루) | `#EAF2FC` ~ `#DCE8F7` (은은한 원형 장식 허용) |
| 하단 밴드(네이비) | `#1B2E6B` (또는 `#16266E`) |
| 제목 기본 | 네이비 `#16266E` |
| 제목 강조어 | 밝은 블루 `#2B6FE0` |
| 포인트/아이콘 | 로열블루 `#2B5BD7` |
| 경고 배지 | 레드 `#E8412E`(!), 앰버 `#F5B301`(주의 삼각형) |
| 확인 아이콘 | 그린 체크 `#2FBF6B` |
| 밴드 위 텍스트 | 화이트 `#FFFFFF` |

`svg_to_png.py --bg` 는 **연블루 배경색과 동일하게**(예: `234,242,252`) 지정한다.

## 텍스트 구성

1. **카테고리 칩** (좌상단): 알약형 배경 `#DCE8F7` + 작은 방패 아이콘(네이비 원) + `"카테고리명 주의"` 텍스트(예: `스미싱/피싱 주의`).
2. **큰 제목** (2줄): 매우 큰 볼드(폰트 90~100px). 기본은 네이비, **핵심어 1개만** 밝은 블루로 강조. 예) `찍기 전에 ` + `**확인하세요**`.
3. **보조 문구**: 제목 아래, 왼쪽에 세로 바(`|`, 로열블루) + 40px 내외 텍스트(`#3A4A7A`).
4. **행동 가이드 캡션** (하단 밴드): 콘텐츠의 4개 행동 가이드에서 3~4개를 뽑아 **아주 짧게**(각 6~10자, 1~2줄) 요약. 각 항목 앞에 원형 아이콘, 항목 사이 얇은 세로 구분선.

## 우측 일러스트 (플랫 벡터)

- 소재: **스마트폰**(가장 흔함), 노트북, 브라우저 창 중 하나를 중심에 두고 + **방패(자물쇠/체크)** + **빨간 원형 `!` 배지** 조합.
- 주제별 소품: 스미싱/피싱 → 문자·QR·봉투 / 악성코드 → 브라우저·퍼즐·톱니 / 개인정보 → 자물쇠·프로필.
- 플랫 스타일, 둥근 모서리, 은은한 그림자. **과도한 공포 연출 금지**(빨간 `!`는 작은 배지 수준).

## 필수 표기 (삭제·수정 금지)

우하단(네이비 밴드 위)에 화이트로:
```
* AI로 생성되었습니다.
```

## SVG 작성 규칙

1. **캔버스**: `<svg width="1672" height="941" viewBox="0 0 1672 941" xmlns="http://www.w3.org/2000/svg">`
2. **배경 먼저**: 전체를 덮는 `<rect width="1672" height="941" fill="#EAF2FC"/>` (투명 영역 방지).
3. **폰트**: 한글은 `font-family="NanumGothic, NanumBarunGothic, 'Apple SD Gothic Neo', sans-serif"`.
4. 제목이 우측 일러스트(대략 x≥1150)와 겹치지 않도록 좌측 텍스트 폭을 관리한다.
5. 하단 밴드는 `path` 로 물결 상단 경계를 만들면 하우스 톤과 잘 맞는다.

### 뼈대 예시 (구조만)

```xml
<svg width="1672" height="941" viewBox="0 0 1672 941" xmlns="http://www.w3.org/2000/svg">
  <rect width="1672" height="941" fill="#EAF2FC"/>
  <circle cx="1500" cy="120" r="360" fill="#DCE8F7"/>            <!-- 은은한 장식 -->

  <!-- 카테고리 칩 -->
  <rect x="95" y="96" width="360" height="70" rx="35" fill="#DCE8F7"/>
  <circle cx="140" cy="131" r="26" fill="#1B2E6B"/>              <!-- 방패 원 -->
  <text x="188" y="142" font-size="30" font-weight="bold" fill="#2B4CA8"
        font-family="NanumGothic, 'Apple SD Gothic Neo', sans-serif">스미싱/피싱 주의</text>

  <!-- 큰 제목 -->
  <text x="92" y="330" font-size="96" font-weight="bold" fill="#16266E"
        font-family="NanumGothic, 'Apple SD Gothic Neo', sans-serif">받은 QR코드,</text>
  <text x="92" y="450" font-size="96" font-weight="bold"
        font-family="NanumGothic, 'Apple SD Gothic Neo', sans-serif">
    <tspan fill="#16266E">찍기 전에 </tspan><tspan fill="#2B6FE0">확인하세요</tspan>
  </text>

  <!-- 보조 문구 -->
  <rect x="94" y="520" width="8" height="44" fill="#2B5BD7"/>
  <text x="120" y="556" font-size="40" fill="#3A4A7A"
        font-family="NanumGothic, 'Apple SD Gothic Neo', sans-serif">출처가 불분명한 QR코드는 촬영하지 마세요</text>

  <!-- 우측 일러스트: 스마트폰 + QR + 방패 + ! 배지 (여기서 작성) -->

  <!-- 하단 네이비 밴드 (물결 경계) -->
  <path d="M0 760 Q 420 720 840 760 T 1672 760 V941 H0 Z" fill="#1B2E6B"/>

  <!-- 행동 가이드 아이콘 3개 + 캡션 (원 + 텍스트 + 구분선) -->

  <!-- 필수 고지 -->
  <text x="1600" y="905" text-anchor="end" font-size="26" fill="#FFFFFF"
        font-family="NanumGothic, 'Apple SD Gothic Neo', sans-serif">* AI로 생성되었습니다.</text>
</svg>
```

## PNG 추출 보장 사항

`scripts/svg_to_png.py` 는 다음을 보장한다.
- 투명·반투명 픽셀 0개 (`--bg` 색으로 합성)
- 모드 RGB
- 크기 정확히 `--width`×`--height` (기본 1672×941, 캔버스 밖 요소 크롭)
- 파일명 `휴대폰안심_매거진_배너_YYYYMMDD.png`
