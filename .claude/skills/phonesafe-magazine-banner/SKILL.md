# PhoneSafe 매거진 배너 이미지 생성

## 개요

보안 매거진 콘텐츠의 핵심 메시지를 1672×941px(16:9) 가로형 배너 이미지로 만든다. **기존에 발행된 배너들과 디자인이 일관되도록** 하우스 스타일을 따라 플랫 벡터 SVG로 디자인한 뒤, 투명 픽셀이 완전히 제거된 RGB PNG로 추출한다.

**배너는 항상 정의된 모든 스타일(현재 A·B·C·D·E 5종)을 생성한다.** 파일명은 `휴대폰안심_매거진_배너_YYYYMMDD_스타일A.png` … `_스타일E.png` 로 저장한다.

| 스타일 | 배경 | 구성 | `--bg` |
|--------|------|------|--------|
| A | 연블루(`#EAF2FC`) + 네이비 물결 하단 밴드 | 카테고리 칩 + 대제목 + 하단 아이콘 3개 + 우측 일러스트 | `234,242,252` |
| B | 진블루 단색 그라디언트(`#1C3FB4→#2E63E0`) | 외곽선 태그 + 흰색 알약 칩 3개 + 우측 흰색 일러스트 | `28,63,180` |
| C | 다크 잉크(`#0F1A2E`) + 민트(`#34D399`) 단색 액센트 | 세로 번호 리스트 01·02·03 + 라인아트 일러스트 | `15,26,46` |
| D | 다크 틸(`#25383B`) + 오렌지(`#F1531F`) 2톤 | 좌측 고지/바코드 사이드바 + 세로 대제목 + 프레임 + 원형 엠블럼 + 우측 글리프 열 (Glyph Beers 라벨풍) | `37,56,59` |
| E | 다크 테크(`#0C1116`) + 앰버(`#E8A33D`) | 좌측 비주얼(글로우) / 우측 필 태그 + 헤드라인 + 서브 + 불릿 3개 + 하단 엔드노트 (테크 슬라이드풍) | `12,17,22` |

모든 스타일이 같은 콘텐츠(카테고리·제목·행동 가이드)를 쓰되 배경·구성·강조색만 다르게 하고, 같은 폴더에 함께 저장한다. 새 참고 디자인이 들어오면 F, G … 로 스타일을 추가한다.

이 스킬은 [[phonesafe-security-magazine]] 스킬의 **후속 단계**다. 콘텐츠 생성이 끝난 뒤 그 산출물(카테고리·제목·행동 가이드)을 입력으로 받아 실행하는 것이 표준 흐름이다. 단독으로도 사용할 수 있다.

## 입력값

phonesafe-security-magazine 산출물 또는 사용자 입력에서 아래를 가져온다.

- **카테고리** — 예: `3) 개인정보 유출`
- **제목** — 배너의 큰 제목이 될 핵심 메시지
- **행동 가이드 핵심어** — 본문 마지막 단락의 4개 항목에서 추출한 짧은 키워드 (보조 문구용)

## 워크플로우

### 1단계: 최초 1회 환경 준비

```bash
bash scripts/setup.sh
```

`cairosvg`, `pillow` 를 설치한다. cairo 시스템 라이브러리가 없어 변환이 실패하면 `brew install cairo pango gdk-pixbuf libffi` 를 실행한다.

### 2단계: 기존 배너 디자인 참고 (필수)

새 배너를 그리기 전에, 이미 발행된 배너들을 열어 디자인 언어를 눈으로 파악한다.

```bash
ls "매거진 프롬프트/매거진 컨텐츠"/*/*.png
```

최근 배너 **2~3개를 Read 로 열어** 배경색·제목 타이포·강조어 처리·하단 밴드·아이콘·일러스트 톤을 확인하고, 새 배너가 그 흐름과 이어지도록 만든다. (가장 최근 폴더의 `보안콘텐츠_*.png` 가 현재 스타일의 기준이다.)

### 3단계: 출력 경로 결정

**콘텐츠 산출물과 반드시 같은 폴더에 저장한다.** phonesafe-security-magazine 실행 직후라면 그 스킬이 출력한 `📁 폴더: ...` 경로(예: `매거진 컨텐츠/260702` 또는 `260702_2`)를 그대로 `--outdir` 에 넘긴다. 배너는 새 폴더를 만들지 않는다.

콘텐츠 없이 배너만 단독 생성하는 경우에만 사용자에게 저장 위치를 확인한다.

### 4단계: SVG 디자인 작성

`references/design-guide.md` 의 하우스 스타일을 따라 `banner.svg` 를 작성한다. 핵심만 요약하면:

- 캔버스 **1672 × 941**, 연블루 배경 + 하단 네이비 밴드(물결 경계)의 2단 구도
- 좌상단 **카테고리 칩**(방패 + "○○ 주의"), **초대형 네이비 제목 2줄**에 핵심어 1개만 밝은 블루 강조
- 제목 아래 **세로 바 + 보조 문구**, 하단 밴드에 **행동가이드 아이콘 3~4개 + 짧은 캡션**
- 우측 **플랫 벡터 일러스트**(스마트폰/방패/빨간 ! 배지 등), 과도한 공포 연출 금지
- 한글은 `font-family="NanumGothic, NanumBarunGothic, 'Apple SD Gothic Neo', sans-serif"`
- **우하단 `* AI로 생성되었습니다.` 문구 필수** (삭제·수정 금지)

전체 팔레트·구도·SVG 뼈대는 `references/design-guide.md` 참조.

### 5단계: PNG 추출

```bash
python3 scripts/svg_to_png.py banner.svg \
  --outdir "매거진 프롬프트/매거진 컨텐츠/YYMMDD" \
  --date YYYYMMDD --bg 234,242,252
```

`--bg` 는 SVG 연블루 배경색과 동일한 RGB 로 지정한다(투명 픽셀을 채워 제거). 해상도는 기본 1672×941이며 `--width/--height` 로 조정 가능. 결과 파일명은 `휴대폰안심_매거진_배너_YYYYMMDD.png`.

`--date` 의 `YYYYMMDD` 는 **실행 당일의 실제 날짜를 먼저 확인해** 넣는다. 시스템 시계(`date`)·파일 mtime을 그대로 믿지 말고, 콘텐츠와 함께 만드는 경우 콘텐츠의 날짜와 반드시 일치시키며, 불확실하면 사용자에게 오늘 날짜를 확인한다.

### 6단계: 렌더 결과 확인

생성된 PNG를 Read 로 열어 한글 렌더·레이아웃·기존 배너와의 일관성을 확인한다. 어긋나면 SVG를 수정해 다시 추출한다.

## 출력 체크리스트

- [ ] **정의된 모든 스타일 생성** (현재 A·B·C·D·E, `_스타일A~E.png`)
- [ ] 기존 배너 2~3개를 참고해 하우스 스타일과 일관되게 제작
- [ ] 캔버스 1672×941, 연블루 배경 + 네이비 하단 밴드 2단 구도
- [ ] 카테고리 칩 + 네이비 대제목(핵심어 블루 강조) + 보조 문구
- [ ] 하단 밴드 행동가이드 아이콘 3~4개 + 우측 일러스트
- [ ] 한글 폰트 family 지정, 우하단 `* AI로 생성되었습니다.` 포함
- [ ] PNG 추출 완료 (투명 픽셀 0개, RGB, 1672×941)
- [ ] 콘텐츠와 동일한 YYMMDD 폴더에 저장
